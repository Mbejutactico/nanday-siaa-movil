APInanday - Ñanday SIAA

La API está funcionando. Todos los servicios (salvo el login) exigen la cabecera Authorization: Bearer <token>.

  • POST /LoginServlet (email, password) → token  ·  DELETE /LoginServlet cierra la sesión
  • POST /c/movil tipo = sesion, centros, almacenes, centrosCosto, insumos, stock, otsConPendientes, ocPendientes, proveedores, insumosCatalogo...
  • POST /c/inventarioControlador tipo = stockAlmacen, kardex, registrarConteo, pendientesSalida, emitirSalida, listarTransferencias, crearTransferencia, anularTransferencia, alertasMinimo...
  • POST /c/otControlador tipo = listar, detalle, almacenesConStock, suministrar, quitarSuministro, finalizar, reabrir...
  • POST /c/ocControlador tipo = obtenerDetalleRecepcion, procesarRecepcion...
  • POST /c/activosControlador tipo = resumen, listar, detalle, registrarMovimiento
  • POST /c/activosMovControlador tipo = activos, crearSolicitud, listarSolicitudes, detalleSolicitud, aprobar, rechazar, enRecepcion, recibir, rechazarRecepcion, anularSalida
  • POST /c/dashboardcontrolador tipo = resumenOT
  • POST /PerfilServlet tipo = ActualizarDatos, CambiarPassword, ActualizarFoto  ·  GET /FotoServlet?archivo=perfil_N.jpg
  • Anteriores: /ProveedorServlet, /InsumoServlet, /UnidadServlet
